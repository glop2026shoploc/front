# front

## Installation

Après avoir cloné ce repo, il faut installer les librairies et tout le reste :) Cela va installer notamment shadcn et playwright pour les tests

```bash
npm install
```

Pour lancer le server :
```bash
npm run dev
```

Pour lancer les tests : 
```bash
npm run test:e2e
```
